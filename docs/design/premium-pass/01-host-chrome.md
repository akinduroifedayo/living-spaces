# Host chrome fixes — Space header, Upkeep panel, Internet access row

Miro → Forge, Nov 11. Source read: `src/desktop/ui/space.jsx`, `schedule.jsx`, `permissions.jsx`, `components.jsx`, `styles.js`; evidence `docs/evidence/runs/sky-same-session-repair/opened.png`, `r1-09-repair/02-progress-repaired.png`.

Principle: the host frame is a quiet picture frame. The Space's own art direction owns the canvas. The chrome says three things at a glance (what this is, how fresh it is, what I can do) and nothing it can't back with a real value.

## 1. Space header bar

### Layout (one row ≥ 900px, two rows below)

```
[‹ Spaces]  [tile] Sky Window  (✓ Ready)                 [Saved 4:02 AM]  [⏱ Every hour]  [History]  [Permissions]  [⟳ Refresh now]  [⋯]
                   Hermes · Updated 4 min ago · 🛡 Sandboxed
```

- Keep tile accent, name, status pill exactly as now.
- Meta line = owner chip + **one** freshness phrase + Sandboxed chip, separated by ` · `. 12px, `--ui-text-secondary`.
- Below 900px: identity on row 1, actions on row 2 right-aligned (current wrap behaviour is fine).

### Freshness phrase (replaces `Last successful update … · source data from …`)

Never render “Not reported”. Pick the first rule that matches:

| Condition | Text (relative, `title=` absolute) |
|---|---|
| `status === 'updating'` or run in flight | `Updating now…` |
| last attempt failed and `last_success_at` set | `Updated 2 h ago · last try failed` (failure banner carries the detail) |
| `last_success_at` set and `source_as_of` set and they differ by > 10 min | `Updated 4 min ago · source data from 3:00 AM` |
| `last_success_at` set | `Updated 4 min ago` |
| upkeep declared, never succeeded | `Not refreshed yet` |
| no upkeep declared | `Edited 12 min ago` (from `updated_at`; omit if null) |

`Time` / `absolute()` fallback: change `'Not reported'` to `'—'` everywhere it can reach UI, and never pass a null into a sentence (the rules above guarantee that). The diagnostic `'Not reported by runtime'` in crash text stays.

Test impact: `status.test.mjs:238-239` and `render-smoke.mjs:72` assert the old sentence. Update to assert `Updated` + the absolute time in the `title` attribute, and `source data from` only when the 10-min gap rule applies (the failed-catch-up fixture: success 1700000000, source 1699999900 = 100 s apart → `Updated … · last try failed`, source phrase omitted).

### Sandbox line

- **Remove** `<div className="ls-caption">Content below the bar is generated by this Space and runs sandboxed</div>`.
- **Add** a quiet chip at the end of the meta line: shield codicon (`shield`) + `Sandboxed`, no border, secondary colour, wrapped in `Tip` with: `Runs isolated from Hermes, your files and other Spaces. See Permissions for what it can reach.` Make the chip a button that opens Permissions (it's the natural "what can this do?" entry).
- Keep `aria-label="Space content"` on the section; change it to `aria-label="Space content, sandboxed"` so screen readers still get the boundary.

### Canvas

Let the Space own the canvas edge to edge. Card-inside-card is the single biggest reason chat-built Spaces look boxed in.

```css
.ls-content{padding:0;gap:0;min-height:420px}
.ls-sandbox{border:0;border-radius:0;min-height:380px}
```
The framebar's existing `border-bottom` is the boundary. Keep `.ls-stale` treatment (failed state) as is.

### Save status

Idle `No unsaved changes` is noise. Render nothing visible when `write` is null (keep the empty `role="status"` live region mounted so later announcements still fire). Saving / Saved / failed / unknown / conflict copy unchanged.

### Upkeep button (replaces `No schedule` / `every 1h UTC` / separate Pause button)

One button, `watch` icon, opens the Upkeep panel:

| State | Label |
|---|---|
| none | `Upkeep` |
| active | humanised cadence: `Every hour`, `Daily 7:00 AM`, `Every 15 min` (fallback: raw cadence in mono) |
| paused | `Upkeep paused` (icon `debug-pause`) |

| running | `Running…` with spinning `refresh` icon |

Drop the separate wide-only Pause/Resume button from the bar; Pause/Resume lives in the panel and the ⋯ menu (keep the menu item).

## 2. Upkeep panel (replaces ScheduleSheet and schedule approval)

Drawer title: `Upkeep · {Space name}`. Description (sr-only): `Native Hermes cron job that keeps this Space current`.

### Active / paused layout, top to bottom

1. **Headline block**
   - Line 1, 20px/600: humanised cadence — `Every hour` · then pill `Active` / `Paused`.
   - Line 2, secondary: active → `Next run in 23 min · 5:00 AM CST`; overdue → `Waiting for Hermes · was due 4:00 AM`; paused → `Paused — no runs until you resume`.
2. **Action row** (left to right): `[▶ Run now]` (primary) `[⏸ Pause]` / `[▶ Resume]` … spacer … `[Remove…]` (danger, ghost).
   - Run now → label `Running…`, `aria-busy`, disabled until the run settles; announce result via the existing live region.
   - Resume disabled while Refresh is revoked; show the reason inline under the row: `Approve Refresh in Permissions to resume.` + `[Open Permissions]` link-button.
3. **Last result** (card, 1 row): status icon + `Succeeded 4:00 AM · 12 records updated` / `Failed 4:00 AM · Source unavailable` + `[View run]` → History runs tab. No run yet → `No runs yet. Run now to try it.`
4. **Prompt** (agent handler): label `Prompt`, body in a quote block (`white-space:pre-wrap`, 13px, max 8 lines then `Show all`), `[Copy]`. Under it, secondary: `Uses model calls on every run.`
   Feed handler instead: label `Source`, `Public feeds from {hosts}` and secondary `No model calls.`
5. **Schedule facts** (`dl.ls-facts`): `Cadence` — `Every hour` + mono `0 * * * *` · `Timezone` — `America/Chicago` · `Job` — mono short id (e.g. `cron_7f3a…`) with Copy.
6. **Recent runs**: up to 5 rows `4:00 AM · Scheduled · Succeeded · 12 updated`. Link `All runs in History`.
7. **Footer, secondary**: `If Hermes is asleep` + existing `CATCH_UP` text. Then `CopyPrompt` labelled `Change prompt or cadence in chat`, text: `{owner}, change the upkeep for {Space}: …`

### Empty (no job)

- Icon `watch`, heading `No upkeep yet`
- Body: `Ask {owner} in chat to keep this Space current. Upkeep runs as a Hermes cron job you can pause or remove here.`
- `CopyPrompt`: `{owner}, keep {Space} current. Refresh it every morning at 7 and tell me what changed.`

### Error states

- Job missing: banner `Hermes can't find this upkeep job. It may have been removed outside Spaces.` actions `[Remove from Space]` `[Ask {owner} to set it up again]` (CopyPrompt).
- Hermes unreachable / readback malformed: banner `Couldn't read the upkeep job from Hermes. Showing the last known settings.` action `[Try again]`. Controls disabled with `title` reason.
- Action failed: inline `Banner kind="failed"` at top with `errorText(e)`; controls re-enable.

### Remove confirmation (`DecisionDialog danger`)

- Title: `Remove upkeep for {Space}?`
- Description: `This deletes the Hermes cron job. The Space and its data stay. You can ask {owner} to set it up again.`
- Confirm `Remove upkeep`, cancel `Keep upkeep`.

### Permissions sheet

Delete the `Scheduled upkeep` pending card from "Waiting for your decision" (no more approval). Replace with one line in Granted when a job exists: `⏱ Upkeep · Every hour · Active` + `[Open Upkeep]`.

## 3. Internet access row (first row of Permissions)

Today it's a secondary button reading `On`/`Off` with `role="switch"`. Make it look and behave like a switch.

```
[🌐]  Internet access                                   On  (●──)
      This Space can load content from and send data to the internet.
      It can't reach your Hermes app, your files or other Spaces.
```

- Row: 16px padding, globe codicon (`globe`) in a 32px rounded tile using the Space's accent at 14% fill, label 14px/600, description 12px secondary, max 2 lines.
- Control: real switch visual — track 36×20, thumb 16, `--ui-accent` when on, `--ui-stroke-secondary` when off, 150ms thumb slide (none under `prefers-reduced-motion`). Visible `On`/`Off` text to its left. Whole row is the hit target (≥ 44px tall); keep `role="switch"`, `aria-label="Internet access"`, `aria-checked`, `aria-describedby` exactly as now so `net-permissions.test.mjs` and `qualify_net.py` keep passing.
- Copy:
  - On: keep the existing consent sentence verbatim (`NET_DESCRIPTION`: "This Space can load content from and send data to the internet. It can't reach your Hermes app, your files or other Spaces."). It carries the "send data" consent meaning and tests assert it.
  - Off: keep `NET_OFF_DESCRIPTION` verbatim, then append one secondary line: `Turn on for web images, fonts, libraries and live embeds.`
  - Requested: pill `Needs your decision`, buttons `[Allow]` `[Don't allow]` replace the switch.
  - Busy: switch `aria-busy`, thumb shows a 10px spinner, row not clickable.
  - Failure: inline under the row, `Couldn't change Internet access. Try again.`
- WebRTC disclosure: **keep the exact copy** (it's consent meaning and asserted verbatim by tests). Restyle only: drop the bordered box, render as an `info`-icon secondary paragraph directly under the row, 12px, `line-height 1.55`. Keep it first and visible without scrolling (`qualify_authority.py`).
