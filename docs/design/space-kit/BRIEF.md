## Direction contract

**THESIS:** the user's work, not a generated landing page. Small native controls, visible navigation, readable lists, and purposeful tile accents replace browser-default forms without changing behavior.

**OWN-WORLD:** inherited Nous light/dark surfaces, system UI type at 14px, blue actions, 8px controls and 12px containers. Eight tile accents identify apps/subjects, never outcomes. Accessible semantic colors may be stronger than host tertiary text.

**STORY:** open, recognize the current view, find a record or check-in, edit and distinguish draft/saving/confirmed/failure/conflict. Empty views explain the first action without fake records.

**FIRST VIEWPORT:** compact app heading and identity tile, view nav, then the task. Research Desk: four compact counters and real freshness, or library beside editor. Daily Practice: date, creation row, check-ins. Gallery: shell, composable atoms and states; sections are examples, not a product dashboard.

**FORM:** precisely scoped extension of an incumbent system; no concept roll or new identity. Code-led. Theme follows prefers-color-scheme in the sandbox, linked to Electron nativeTheme by Desktop. Desktop end-to-end theme switching remains Forge's qualification.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

Documentation boundary: the token-bearing CSS and README in this folder document the inherited extension, not a new global design system. Synthetic fixture captions remain visible in visual receipts. Static frames are not Desktop/chat/persistence evidence.
