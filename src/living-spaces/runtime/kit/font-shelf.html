Latin coverage, local files

Only the upstream Latin subsets are bundled. Other scripts use the browser's available fallback fonts. Italic faces and other weights are not included. Missing font files also leave the system fallbacks in place.

The Thai sample depends on a platform font, not this shelf. The fallback comparisons above omit each bundled family explicitly. To test missing files, remove a font stylesheet or its WOFF2 files from a disposable copy. This specimen alone is not proof that a platform loaded the fonts.

Request all three library keys to copy this page's font files and licenses. In a Space, copy this page as kit/font-shelf.html and use that path as the manifest entry. For an entry at the project root, change the three stylesheet links to vendor/fonts/<family>.css. Default Spaces copy none of these optional files.
