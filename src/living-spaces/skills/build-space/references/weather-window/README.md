# Weather Window · a Space without the kit look

Copy `space.json`, `index.html`, `styles.css`, `app.js` into a Space. It needs no kit CSS, framework, library or font. It saves the last forecast loaded for each city in a `forecasts` record, so a reopened Space can still show it while live weather is unavailable. City selection is explicitly volatile. No geolocation or account is used.

This is a **dashboard** composition: current temperature and conditions at the left, twelve actual hourly forecasts at the right, exact values behind a native disclosure. SVG geometry comes from a linear scale over response values; it is not a decorative trend. Both daylight and dark palettes are authored.

It loads the public Open-Meteo forecast through the host: `const response = await space.net.fetch(url, {as: 'json'})`. The result is `{status, url, headers, json}`; the app checks `response.status` before reading `response.json` (there is no `.json()` method). Browser `fetch` is blocked by the frame and is never used. Attribution links to Open-Meteo; forecasts are estimates, not observations. Provider availability and terms need to be checked for a shipping derivative. It requests no secrets.

The app loads live data when available, retains the last forecast on a later failure, rejects incomplete responses, supports retry, ignores superseded responses and has a twelve-second timeout. **Explore sample** is a user-chosen, clearly labelled synthetic dataset, never a silent fallback passed off as live weather. Internet access is on by default. If the user turns it off in Permissions, `space.net.fetch` rejects with `code === 'not_granted'` and the app says "Internet access is off for this Space" while showing the last forecast or sample (the saved forecast survives the reopen that a permission change causes); any other failure names a generic load failure and never claims to know the permission state. Opened outside the Space runtime (no `space.net`), it offers only the sample.

Exercise it as a saved Space (create, then edit, through the write tools) so it runs behind the real frame policy and host network path; a static HTTP render proves neither. In an offline sandbox the sample still works. Screenshots and executed states are recorded under `docs/design/space-kit/`.
